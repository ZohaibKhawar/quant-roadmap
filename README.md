# How to become a quant

A free, stage-by-stage roadmap to becoming a quant researcher, trader or developer.

**[Open the roadmap](https://zohaibkhawar.github.io/quant-roadmap/)**

- Six stages: maths, probability and statistics, programming, markets, proof of work, and getting hired
- Pick a role and the checklist marks what's core, useful or optional for it
- A worked practice problem at each stage, to test whether you're ready to move on
- Progress is saved in your browser only; there are no accounts
- A live random-walk simulation that compares a closed-form answer with Monte Carlo

## Run it locally

It's a static site with no build step:

```bash
python -m http.server 5300
```

Then open http://localhost:5300.

## Corrections

Hiring dates, pay and links go out of date. If you spot a mistake, please [open an issue](https://github.com/ZohaibKhawar/quant-roadmap/issues).
